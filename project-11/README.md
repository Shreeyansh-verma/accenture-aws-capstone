# Project 11 - Infrastructure Changes with Branching Policy

## Objective
Demonstrate infrastructure changes using Git feature branches
and a reviewed GitHub Pull Request.

## Infrastructure Change
Added Terraform configuration for an AWS CloudWatch log group
with a seven-day log retention policy.

## Workflow
1. Create feature branch from main.
2. Add Terraform infrastructure changes.
3. Validate Terraform.
4. Commit and push feature branch.
5. Create Pull Request targeting main.
6. Review changes and merge PR.

## Note
Terraform configuration is added for version control demonstration.
No AWS infrastructure is deployed by this project.
