# Project 6 - Version Control with Git and GitHub

## Objective
Demonstrate Git branching, commits, GitHub remote
repositories, and the Pull Request workflow.

## Workflow
1. Create a feature branch.
2. Add Terraform configuration.
3. Validate the configuration.
4. Commit changes.
5. Push the feature branch.
6. Create a Pull Request targeting main.

## Terraform Configuration
Defines reusable project and environment tags
without provisioning AWS resources.

## Deliverable
GitHub Pull Request link and screenshot.
